# ZeroWalker — 设计起点

> 三栏写法：**已确认** = 现在就是这样；**建议（待试玩确认）** = 做出来了但手感/数值没定；**待决定** = 还没做、也没定。
> 推翻旧结论时不要删，改成删除线并在行尾写「作废 日期」。

## 一句话

2D 横版冒险闯关：折纸枪手 Blitz 在关卡里跑、跳、冲刺、射击与近战，清掉挡路的目标。

## 已确认

| 主题 | 结论 |
| --- | --- |
| 类型 | 2D 横版动作闯关，单人，无联网 |
| 视角 | 侧视正交相机，跟随玩家，视野高度约 10 个单位（orthographic size 5） |
| 主角 | Blitz：折纸风格枪手，Spine 骨骼动画，持枪，枪口有骨骼定位点 |
| 动作 | 移动（A/D）、跳跃（空格）、冲刺（左 Shift）、射击（鼠标左键按住连射）、近战（F） |
| 射击 | 子弹沿朝向直线飞行，命中目标扣血；按住扳机时由动画事件 `OnAttack` 触发连发 |
| 近战 | 播放 `Skill_02` 动作，播完回待机；**只有表现，没有伤害判定** |
| 冲刺 | 固定距离的位移，带冷却；冷却从冲刺开始计时；**地面与空中都能用** |
| 目标物 | 靶子：3 血，受击闪色，死亡后 2 秒原地复活（用于验证打击反馈，不是正式敌人） |
| 地形 | 静态碰撞体（地面/平台），键盘操作，无需鼠标瞄准：射击固定朝角色朝向 |
| 平台 | Windows PC + Android；Android 最低 API 22 |
| 数据 | 全部手感数值在 `Assets/Resources/Content/data/*.json`；全部文案在 `Content/i18n/ui.csv` |
| 输入 | 新版 Input System Package，键位可在 `input.json` 改 |

## 建议（待试玩确认）

| 主题 | 现状 | 要确认什么 |
| --- | --- | --- |
| 冲刺手感 | 4 米 / 0.2 秒 / 冷却 0.7 秒 | 像「瞬移」还是「冲刺」？是否要加速度曲线或残影 |
| 空中冲刺 | 与地面共用同一条 0.7 秒冷却，不限次数 | 是否要限制「每次起跳只能冲一次」，或空中冲刺距离短一点 |
| 跳跃手感 | 初速 9、重力沿用刚体设置、无二段跳 | 跳跃弧线是否够长；要不要土狼时间/缓冲跳 |
| 相机 | 偏移 1.15、平滑 0.15、不锁 Y | 跑跳时上下浮动是否晕；要不要锁 Y 或加前瞻 |
| 特殊弹 | 青色、1.2 倍大小、攻击连射时由动画事件射出 | 与普通弹区分是否够明显 |
| 靶子反馈 | 3 血、闪色 0.08 秒、死亡缩小到 0.6 | 打击感是否足够（是否需要顿帧、震屏） |

## 待决定

| 主题 | 说明 |
| --- | --- |
| Android 触屏操作 | 目前只有键鼠绑定；手机需要虚拟摇杆 + 开火/跳跃/冲刺按钮，属于新功能，未做 |
| 关卡内容 | 关卡的组成方式（房间拼接 / Tilemap / 手工摆放）、检查点、通关条件都未定 |
| 正式敌人 | 移动逻辑、攻击方式、受击与死亡反馈都未定；当前靶子只是测试用 |
| 玩家生命与死亡 | 没有受击、无敌帧、死亡与重生流程 |
| 存档 | `JsonManager` 已就位（LitJson），但没有需要持久化的数据；进度/解锁/设置字段待定 |
| 音频 | 没有音效与音乐资源 |
